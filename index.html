System Flow

How RakshaAI intercepts a scam in real time

Five stages, from signal capture to user alert — the same pipeline running behind the two consoles in this prototype.

1

Signal Capture

Incoming call, SMS, WhatsApp text, or a UPI transaction request is captured.

2

Vernacular NLP Scan

Speech-to-text (regional language) → scam-intent classifier scores manipulation patterns.

3

Transaction Risk Engine

Ensemble model (RF + XGBoost + Isolation Forest) scores the linked transaction pattern.

4

Fusion Risk Score

Both scores combine into a single real-time risk index.

5

User Alert / Block

High risk → voice alert in local language, soft transaction hold, report-to-1930 shortcut.

Try it yourself: run a message through Tab 1, a transaction through Tab 2, then open Tab 3 to see both fuse into one decision — the same way a bank's fraud desk would see it.
